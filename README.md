# Superstore Sales Performance & Profit Optimization Dashboard

End-to-end retail analytics project using Python, MySQL, and Power BI.

## Workflow
Raw Superstore data → Python cleaning & EDA → MySQL business analysis → Power BI dashboard → business optimization insights.

## Project components
- `Retail-Performance-Optimization.pbix` — completed interactive Power BI dashboard.
- `python/data_cleaning.py` — reusable data preparation pipeline.
- `notebooks/retail_analysis.ipynb` — full EDA, KPI, performance, profitability, discount, and optimization analysis.
- `sql/` — schema, loading, business analysis, and advanced SQL queries.
- `data/` — raw/processed data, Power BI supporting tables, and SQL result exports.

## Core KPIs
- Total Sales: ~$2.327M
- Total Profit: ~$292.3K
- Total Orders: 5,111
- Total Quantity: 38,654
- Profit Margin: 12.56%
- Average Order Value: $455.20

## Tools
Python, Pandas, NumPy, MySQL, SQL, Power BI, DAX, Jupyter Notebook, Git/GitHub.
